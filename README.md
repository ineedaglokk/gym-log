# Журнал тренировок — Telegram Mini App

Дневник фулбоди-тренировок (пн / ср / пт): вес и повторы по каждому подходу, автоподстановка веса для следующей тренировки, сводка прогресса за месяц и календарь на год.

Вкладка «Год» → «Прогресс»: сводка текущего месяца (листается по месяцам). Как считается прогресс: тренировка оценивается по лучшему подходу — усталый последний подход её не портит. Чтобы сравнить «больше веса, но меньше повторов», внутри используется вес × (1 + повторы/30) — один повтор ≈ 3% веса; на экран это число не выводится, там только килограммы и повторы. Не меньше веса и не меньше повторов, а чего-то больше — всегда прогресс (+1 повтор тоже); вес вырос, а повторы упали (или наоборот) — решает формула, разница меньше 2% — «на уровне». Если лучший подход не лучше, но всего сделано больше — тоже прогресс. Для упражнений с весом тела к доп. весу прибавляется записанный вес тела (один и тот же для обеих сравниваемых тренировок); без него засчитываются только очевидные случаи. Планки и кардио — по времени. «Стало лучше» — последняя тренировка месяца сильнее первой; «Просело» — слабее предыдущей. Если на том же весе в конце на 2+ повтора больше — приложение говорит, что в начале был запас. Вес сам не растёт: в следующий раз подставляются веса прошлого раза. Когда все подходы прошлого раза были на одном весе и все до верха цели (например, 15 кг × 12, 12, 12), и сегодня это упражнение ещё не начато, под ним появляется кнопка «⬆ Прокачать до 17 кг» — единственная кнопка такого рода: нажал, и новый вес встаёт во все ещё не сделанные подходы; повторное нажатие возвращает старый. Если в прошлый раз вес поднимали по ходу (60, 65, 70) и тяжёлый подход вышел в диапазоне — кнопки нет, только напоминание «можно сразу начать с 70 кг». Ячейки повторов всегда по диапазону из программы: зелёная — в цели, тёмно-зелёная — верх цели, красная — меньше цели; если вес выше, чем в прошлый раз (поднял сам или нажал «Прокачать»), красной не бывает. Клавиатура закрывается нажатием в любое место вне поля. Кнопка ✕ у упражнения — пропустить его сегодня (тренажёр занят и т.п.): карточка сворачивается в «Пропущено сегодня · Вернуть», пропуск хранится в записи дня, на прогресс и «прошлый раз» не влияет; если подходы уже вписаны, нужно нажать второй раз. У каждого упражнения есть заметка на следующий раз (значок сообщения рядом с «i»): в следующую тренировку этого упражнения она видна как «С прошлого раза», и можно написать новую. Заметки не копятся — видна только заметка с последней тренировки; хранятся в облаке Telegram и боту не отправляются. Разминку можно записать кнопкой «+ разминка» под упражнением: она хранится отдельно от рабочих подходов, показывается в «прошлый раз» и подставляется в следующий раз. В силу разминка засчитывается, только если какой-то разминочный подход сильнее рабочих; в объём и в подсказку про лёгкий старт не идёт. Нажатие на упражнение раскрывает график за всё время, на дату — открывает ту тренировку.

- При первом заходе программа пустая: каждый собирает свою сам (или берёт готовую схему и правит). Тем, кто уже записывал тренировки по старой встроенной программе, она остаётся. Каждый пользователь бота собирает свою программу во вкладке «Программа»: упражнения, подходы, диапазон повторов, шаг веса, дни тренировок. Программой можно поделиться кодом `GYM1:…`.
- Каталог упражнений (`cat.js`, 1045 шт.): названия, группы мышц, подгруппы и ссылки — страницы [fitpush.ru](https://fitpush.ru/exercises/), список собран пользователем вручную. Значок снаряда и тип подхода (повторы / секунды / минуты) проставлены нами. Картинка на карточке — картинка страницы упражнения на fitpush (`/assets/exercises/share-cards-v2/<адрес>.jpg`, грузится с fitpush, к себе не копируется); если не загрузилась — фото из [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (общественное достояние, есть у 107), иначе значок снаряда на цвете группы.
- Кнопка «i» и нажатие на упражнение открывают его страницу на fitpush в браузере Telegram (встраивать fitpush, как и seto, сайт не разрешает). Для упражнений не из каталога — поиск seto по названию. Ничего с этих сайтов не собирается и не копируется.
- Старые сохранённые программы переезжают на новый каталог сами: таблица `m` в `cat.js` (161 название прежнего каталога seto → упражнение fitpush, ходовые подобраны вручную) и `OLD2NEW` в `app.js` для самых первых программ. Название из прежнего каталога заменяется новым, своё название остаётся; упражнения без пары остаются как были. Записи тренировок привязаны к упражнению программы, а не к названию, поэтому история не теряется.
- Своё упражнение (внизу библиотеки): название, группа мышц, снаряд и как считать (повторы / секунды / минуты); подходы, повторы и шаг веса подставляются как у упражнений каталога. Группу и снаряд можно поменять в настройках упражнения; в программе у него значок снаряда на цвете группы.
- Без сервера и сборки: `index.html`, `app.js`, `cat.js`, папка `img/`.
- Записи хранятся в облаке Telegram (CloudStorage) у каждого пользователя бота. Открытый не через Telegram, журнал сохраняет записи в браузере.
- Размещается на GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
- Подключается к боту в @BotFather: Bot Settings → Configure Mini App (или Menu Button) → ссылка вида `https://<логин>.github.io/<репозиторий>/`.

## Как устроены данные

Ключ `program` — программа пользователя. Ключ `w_ГГГГ-ММ-ДД` на каждую тренировку, значение — JSON:

```json
{"date":"2026-10-23","bw":82,"ex":{"legpress":{"w":[100,120,131],"r":[12,12,12]}}}
```

`w` — вес каждого подхода, `r` — повторы. Если в подходе сделана верхняя граница повторов, в следующий раз вес этого подхода увеличивается на шаг упражнения.

## Бот «Шлёпа»

Папка `bot/` — Telegram-бот на Cloudflare Workers (бесплатный тариф): приветствие на /start с кнопкой «Открыть качалку», напоминания в дни тренировок и разбор через 2 часа после тренировки (где вес вырос или просел по сравнению с прошлым разом; ночью, с 23 до 8, разбор ждёт утра). Под напоминанием — кнопки «Уже бегу», «Болею», «Завал на работе», «Нет сил», «Перенесу на завтра»: бот отвечает, запоминает ответ и вспоминает его в следующем напоминании; после «Болею» через день спрашивает о самочувствии и до «Уже лучше» не шутит и не подгоняет. В дни отдыха днём, примерно 2–3 раза в неделю, присылает случайный прикол; команда /fun — прикол сразу. Все фразы — в `bot/lines.js`, туда можно дописывать свои. Сообщения включены по умолчанию; во вкладке «Программа» выключаются целиком или только приколы. Выкладывается сам через GitHub Actions (`.github/workflows/bot.yml`) при изменениях в `bot/`; нужны секреты репозитория `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `BOT_TOKEN`. Мини-апп отправляет боту настройки напоминаний (вкл/время, дни и названия тренировок, часовой пояс) и по сегодняшней тренировке — только сравнение с прошлым разом: название упражнения, лучший подход сегодня и в прошлый раз, дату прошлого раза. Весь журнал бот не получает. Подпись Telegram (initData) проверяется на стороне бота; бот проверяет очередь каждые 15 минут. У каждого пользователя свои настройки, имя берётся из его профиля Telegram; журнал и программа по-прежнему хранятся в облаке Telegram у каждого своё.
